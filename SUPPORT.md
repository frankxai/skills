# Get help

| Need | Best place |
| --- | --- |
| How to use a skill, or share a working example | [Shared skills discussions](https://github.com/frankxai/claude-skills-library/discussions) |
| A reproducible bug in this pack | [Bug report](https://github.com/frankxai/skills/issues/new/choose) |
| A new skill or improvement idea | [Skill request](https://github.com/frankxai/skills/issues/new/choose) |
| A security vulnerability | [Private security report](SECURITY.md) |
| A conduct concern | [Code of conduct reporting](CODE_OF_CONDUCT.md) |

This is a community maintained project. Include the skill name, agent, version if known, and a minimal example when asking for help. Remove secrets and personal data before posting.
